Описание

После выбора оплаты картой кнопка «Оплатить» остаётся неактивной, хотя все поля заполнены.

Шаги воспроизведения

  1. Оформить заказ
  2. Выбрать «Картой онлайн»
  3. Заполнить данные карты
  4. Попробовать нажать «Оплатить»

Ожидаемый результат

Кнопка становится активной после заполнения полей.

Фактический результат

Кнопка остаётся серой, оплатить нельзя.
